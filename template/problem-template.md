# Judul Soal 

## Deskripsi Soal
Tuliskan penjelasan singkat mengenai permasalahan yang harus diselesaikan di sini. 



---

## Contoh

### Contoh 1:
* **Input:** `nums = [2, 7, 11, 15]`, `target = 9`
* **Output:** `[0, 1]`
* **Penjelasan:** Karena `nums[0] + nums[1] = 2 + 7 = 9`, maka kita mengembalikan indeks `[0, 1]`.

### Contoh 2:
* **Input:** `nums = [3, 2, 4]`, `target = 6`
* **Output:** `[1, 2]`

---

## Batasan (Constraints)
* `2 <= nums.length <= 10^4`
* `-10^9 <= nums[i] <= 10^9`
* `-10^9 <= target <= 10^9`
* Hanya ada satu jawaban valid yang tersedia.
